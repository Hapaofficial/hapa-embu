==================================================
A. SEPARATE PUBLIC-MEDIA STORAGE
==================================================

Public profile and portfolio images must never use:

- hapa-private-documents
- hapa-staging-private-documents
- private_documents
- upgrade_documents
- the DOCUMENT_S3_* credentials

Create a separate public-media storage abstraction.

Environment variables:

PUBLIC_MEDIA_STORAGE_MODE=local|s3
PUBLIC_MEDIA_S3_BUCKET
PUBLIC_MEDIA_S3_ENDPOINT
PUBLIC_MEDIA_S3_REGION
PUBLIC_MEDIA_S3_ACCESS_KEY_ID
PUBLIC_MEDIA_S3_SECRET_ACCESS_KEY
PUBLIC_MEDIA_S3_FORCE_PATH_STYLE

LOCAL MODE

For local development:

- store sanitized files in var/public-media/
- keep the directory outside public/
- add it to .gitignore
- never expose local filesystem paths
- serve images only through the public-media API route

S3 MODE

Prepare support for a completely separate bucket.

Future staging bucket:

hapa-staging-public-media

Future production bucket:

hapa-public-media

Both buckets may remain private. Public images should be delivered through a controlled HAPA public-media route or short-lived URLs.

Add a hard safety check:

- PUBLIC_MEDIA_S3_BUCKET must not equal DOCUMENT_S3_BUCKET
- if they are equal, public-media uploads must fail with controlled 503
- do not allow public portfolio uploads to fall back to the private-document bucket

Use a separate adapter, for example:

lib/publicMediaStorage.js

Do not reuse private-document object keys.

Public-media object keys must be PII-free, equivalent to:

professional-profiles/{profileId}/{imageId}.jpg

Do not include email, phone, legal name, ID number or original filename.

C. PUBLIC IMAGE SANITIZATION
==================================================

Public profile and portfolio images must still use:

- multipart/form-data
- actual magic-byte validation
- JPEG / PNG / WebP only
- sharp decode and re-encode
- auto-orientation
- EXIF/GPS stripping
- maximum dimensions
- safe generated keys
- SHA-256
- no original file retention

Limits:

- one public profile photo
- maximum 12 portfolio images

Public image endpoints must return:

- correct sanitized Content-Type
- X-Content-Type-Options: nosniff
- ETag or equivalent cache validator
- safe cache policy
- no storage credentials
- no permanent raw bucket URL
