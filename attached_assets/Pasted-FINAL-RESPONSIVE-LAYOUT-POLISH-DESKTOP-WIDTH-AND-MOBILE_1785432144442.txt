1. DESKTOP WIDTH

- Increase the useful desktop content width.
- Use a responsive max-width around 1280–1440px where appropriate.
- Reduce excessive empty margins on large monitors.
- The dark header background may span the full browser width, while its internal content remains centered.
- Forms and marketplace content must not remain unnecessarily narrow.
- Preserve readable line lengths for legal/help text.

2. MOBILE MAIN NAVIGATION

At widths below approximately 768px, do not render the desktop navigation as multiple wrapped rows.

Create a professional mobile navigation pattern.

Preferred implementation:
- compact top header with HAPA logo, account badge and logout/menu control
- fixed or sticky bottom navigation for the most important customer sections:
  - Home
  - Marketplace
  - Requests
  - Account
  - More

Inside “More” provide:
- Professional roles
- Help
- Owner dashboard when the logged-in user is Owner

Alternative mobile navigation is acceptable only if it is equally clear and app-like.

Requirements:
- no wrapped desktop menu
- no overlapping items
- active section clearly highlighted
- minimum 44px touch targets
- correct safe-area padding
- Owner controls must not dominate the customer navigation
- logout must remain accessible but separated from normal navigation

3. MARKETPLACE SECONDARY NAVIGATION

For:
- Browse
- Pros
- Shops
- Transport
- Sell
- My Listings
- Saved

Requirements:
