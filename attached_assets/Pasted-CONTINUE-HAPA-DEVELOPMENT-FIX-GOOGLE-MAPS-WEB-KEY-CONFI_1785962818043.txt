CONFIRMED DEFECT

HAPA currently has inconsistent Google Maps browser-key handling:

* `lib/maps.js` correctly prefers `GOOGLE_MAPS_WEB_KEY` and supports legacy `GOOGLE_MAPS_BROWSER_KEY`.
* `/api/rides/config` correctly uses `maps.publicWebKey()`.
* The older driver/service map picker in `public/index.html` still calls `/api/public/config` and expects `mapsBrowserKey`.
* `/api/public/config` in `routes/account.js` reads only `process.env.GOOGLE_MAPS_BROWSER_KEY`.
* Some documentation still instructs the Owner to use only the legacy key.

Therefore, configuring the preferred `GOOGLE_MAPS_WEB_KEY` may leave the older map picker disabled even though the new Maps system recognizes the key.
