# Production roadmap

## Phase 1
- Deploy backend to a cloud host
- PostgreSQL database
- HTTPS and domain
- User authentication and OTP
- Role-based permissions
- Error monitoring and backups

## Phase 2
- Google Maps and Places
- Driver GPS streaming
- Distance and fare calculation
- Automatic dispatch and cancellation rules
- Push notifications

## Phase 3
- Safaricom Daraja / M-Pesa
- Wallet ledger and reconciliation
- Merchant settlements
- Driver earnings and commissions
- Refund process

## Phase 4
- Flutter customer, driver and merchant apps
- Android closed testing
- Privacy policy, terms and support workflow
- Google Play release
- iOS TestFlight and App Store review
